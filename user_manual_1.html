ระดับคะแนน

เกณฑ์การให้คะแนน Skill

ใช้เกณฑ์นี้เป็นมาตรฐานกลางในการประเมินพนักงานทุกตำแหน่ง

ระดับชื่อระดับคำอธิบายตัวอย่าง
1 พื้นฐาน รู้จักแนวคิด ต้องมีคนช่วยชี้แนะ เพิ่งเริ่มเรียนรู้ ยังต้องการการดูแล
2 กำลังพัฒนา ทำงานได้บ้างโดยไม่ต้องการความช่วยเหลือมาก ทำงานประจำได้ แต่งานซับซ้อนยังต้องปรึกษา
3 ชำนาญ ทำงานได้อย่างอิสระและมีประสิทธิภาพ แก้ปัญหาได้เอง สอนผู้อื่นในบางเรื่องได้
4 เชี่ยวชาญ เป็น Expert ในสายงาน พัฒนาต่อยอดองค์ความรู้ได้ เป็นที่ปรึกษาให้ผู้อื่น สร้างนวัตกรรมใหม่

GAP คืออะไร? GAP = Expected Level − Actual Level. ถ้า GAP เป็นบวก หมายถึงต้องพัฒนาเพิ่ม ถ้า GAP เป็น 0 หรือลบ หมายถึงตรงเป้าหรือดีกว่าที่กำหนด

FAQ

คำถามที่พบบ่อย

คำตอบสำหรับปัญหาที่พบบ่อยในการใช้งาน

ค้นหาพนักงานแล้วไม่พบ ทำอย่างไร?

ลองค้นด้วยรหัส, ชื่อ, หรือตำแหน่งแทน เช่น "66035" หรือ "HRD" หรือ "Specialist" ระบบมีพนักงาน GJS และ GST ครบ 1,470 คน ถ้ายังไม่พบให้แจ้ง HR เพื่ออัปเดตฐานข้อมูล

กดบันทึกไป Google Sheet แล้วไม่แน่ใจว่าสำเร็จไหม?

หลังกดบันทึกจะมีข้อความ "✅ บันทึกสำเร็จ" ปรากฏมุมขวาล่าง สามารถตรวจสอบที่ Google Sheet ได้โดยตรง ถ้าไม่สำเร็จให้ใช้ Export CSV แทนและแจ้ง HR

สามารถเพิ่ม Skill ที่ไม่อยู่ใน list ได้ไหม?

ได้เลย! ในหน้าประเมิน Skill มีช่องด้านบนตาราง ให้ใส่รหัส Skill, ชื่อ Skill และ Expected Level แล้วกดปุ่ม "เพิ่ม" หรือจะใช้ปุ่ม AI Suggestion ให้ระบบแนะนำก็ได้

Dashboard ใน Google Sheet ไม่อัปเดต ทำอย่างไร?

เปิด Google Sheet → กด menu "📊 HRD Tools" → เลือก "🔄 Refresh Dashboard" Dashboard จะอัปเดตทันทีจากข้อมูลทั้งหมดใน Sheet1

AI Suggestion ไม่ทำงาน ทำอย่างไร?

AI Suggestion ต้องการ Internet และ Claude API ถ้าใช้งานไม่ได้ ระบบจะแสดง Skill แนะนำพื้นฐานให้อัตโนมัติ สามารถเพิ่ม Skill เองได้เช่นกัน

ต้องการความช่วยเหลือ?

ติดต่อทีม HRD เพื่อรับความช่วยเหลือหรือรายงานปัญหาการใช้งาน
